# 关于我

你好，我是 **SoneM1yk**。

这里是我的个人博客，用来记录编程、阅读、生活，以及那些值得被留下的想法。与其说是“作品集”，我更愿意把它当作一个长期维护的笔记本：内容不必完美，但要真实；更新不必频繁，但要持续。

## 我在做什么

- 学习与实践软件工程
- 整理技术笔记和工具使用经验
- 阅读，并尝试把读到的内容变成自己的理解

## 关于这个站点

博客使用 [Astro](https://astro.build/) 与 [Shirone](https://github.com/LyraVoid/Shirone) 主题构建，部署在 GitHub Pages 上。感谢这些开源项目及其贡献者，让搭建个人空间变得简单而愉快。

如果你想联系我，可以从 [GitHub](https://github.com/SoneM1yk) 找到我。
